# CHANGELOG

## 1.1.5 — 2026-11-05

Основа: 1.0.7. Улучшения из 1.1.0 автоматически не переносились.

### Удалено

- **Шеринг (LAN-прокси / QR-код).** Причина: работал нестабильно
  (LAN-inbound конфликтовал с активным VPN-ядром), плюс сокращение
  поверхности атаки и повышение приватности. Удалены страница, движок
  `ShareProxyEngine`, direct-конфиги, зависимость `qrcode`, пункты UI и
  упоминания в документации.

### Добавлено

- **Watchdog Zapret** — слежение за `winws.exe`, автоперезапуск до 3 попыток
  с уведомлением.
- **История проверок** — результаты блокчеков в SQLite (`cache.db` в
  `%APPDATA%\Zentrix`) и сводка доступности за 7 дней по каждому сервису.
- **Сценарии «если → то»** — «если YouTube недоступен → сменить стратегию»,
  «если VPN пропал → включить Zapret», реакции на смену IP.
- **Ping серверов + «Выбрать лучший»** — TCP-замер задержки каждого сервера,
  переключение на минимальный.
- **Алерты смены IP** — тост «IP изменился: был …, стал …».
- **Палитра команд Ctrl+K** — быстрый поиск по страницам и действиям.
- **Авто-тема «Как в Windows»** — чтение реестра `AppsUseLightTheme`,
  реакция на смену темы на лету.
- **Game Mode** — высокий приоритет процессам игр + план питания
  «Максимальная производительность», автовосстановление при выключении.
- **Инструменты** — починка сети (flushdns, Winsock, сброс IP-стека, кэш
  Zentrix), смена DNS в один клик (Cloudflare/Google/AdGuard/Family/DHCP),
  редактор hosts с анти-рекламным пресетом и групповым включением/выключением,
  диагностика ping/traceroute/whois/скан портов.
- **Подписки** — URL подписки и авто-обновление по интервалу.
- **Поиск бесплатных ключей (BETA, по умолчанию выключен)** — только известные
  публичные репозитории-подписки, декодирование Base64/YAML, фильтр
  vless/vmess, проверка доступности, добавление строго вручную с пометкой
  «BETA / не проверено».

### Изменено

- **Навигация перестроена по трём уровням приоритета:**
  главная — только статус и быстрые действия; вкладки уровня 2 — Zapret,
  VPN, Проверки, Инструменты, Мониторинг; служебное (Обновления, Настройки) —
  внизу навигации, на главной — только мелкие ссылки.
- **Механизм обновления компонентов проверен и укреплён:** валидация zip до
  распаковки, докачка при обрыве (HTTP Range), атомарная замена движка с
  откатом при ошибке, сохранение пользовательских `lists/` и игрового фильтра,
  подробное логирование (версии, источник, результат). Happ/Hiddify явно
  помечены как отдельные установщики без тихой автоустановки.

## 1.1.6 — 2026-11-05

### Добавлено

- **TG WS Proxy (встроенный движок).** Локальный MTProto-over-WebSocket мост
  для Telegram Desktop на ядре [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy).
  Работает внутри Zentrix: отдельный поток со своим asyncio-loop,
  потокобезопасная остановка, лог ядра — в интерфейс Zentrix. Никаких
  сторонних процессов с собственным GUI и второй иконки в трее.
  - Управление на вкладке Zapret: включение, порт, автозапуск, подключение
    Telegram по `tg://proxy`-ссылке.
  - Статус — третьей пилюлей на Главной.
  - Обновление: новый компонент «TG WS Proxy» на вкладке Обновления —
    скачивает исходники релиза Flowseal/tg-ws-proxy, валидирует архив и
    атомарно заменяет ядро с откатом при ошибке.
- Зависимости: httpx[http2], certifi, cryptography.

### Изменено

- README полностью переписан под актуальные функции (без скриншотов).
- Сайт-демо обновлён под новую навигацию и функции, раздел скриншотов удалён.
