# Решение проблем

Сначала загляните в лог:

```
%APPDATA%\Zentrix\logs\zentrix.log
```

Открыть быстро:

```powershell
notepad "$env:APPDATA\Zentrix\logs\zentrix.log"
```

Лог перезаписывается при каждом запуске; старые записи ищите в
`zentrix.log.1` (если включена ротация).

## Приложение не запускается

1. Убедитесь, что это Windows 10/11 x64. Qt 6 не поддерживает 32-битную систему.
2. Запустите `Zentrix.exe` из проводника и посмотрите, появляется ли окно.
   Если процесс сразу исчезает — проверьте лог.
3. Для portable-сборки не перемещайте `Zentrix.exe` отдельно от папки
   `_internal` и `engines`.
4. Антивирус может блокировать неподписанный exe. Добавьте папку Zentrix в
   исключения (только если доверяете источнику сборки). Официальные сборки
   подписаны, начиная с версии, указанной в релизе.
5. SmartScreen: «Подробнее» → «Выполнить в любом случае» для своей сборки.

Диагностика:

```powershell
Get-Process Zentrix -ErrorAction SilentlyContinue
Get-Item "$env:LOCALAPPDATA\Programs\Zentrix\Zentrix.exe"
Get-Content "$env:APPDATA\Zentrix\logs\zentrix.log" -Tail 80
```

## Запускается второй экземпляр, но окно не появляется

Zentrix использует мьютекс `Local\Zentrix.SingleInstance.v1` и локальный сервер
`Zentrix.SingleInstance.v1`. Второй процесс должен развернуть уже открытое окно.
Если этого не происходит:

1. Закройте все процессы Zentrix в диспетчере задач.
2. Убедитесь, что не осталось зависшего процесса `Zentrix.exe`:
   ```powershell
   Get-Process Zentrix -ErrorAction SilentlyContinue
   ```
3. Запустите приложение снова. Если окно всё равно не появляется,
   перезагрузитесь — именованный канал (`\\.\pipe\Zentrix.SingleInstance.v1`)
   освободится вместе с процессом.

Если окно свёрнуто в трей — дважды кликните по иконке в области уведомлений.

## Нет иконки в трее

- Проверьте, не скрыта ли она в переполнении панели задач (стрелка вверх).
- Перезапустите проводник: `taskkill /f /im explorer.exe; start explorer.exe`.
- В настройках выключите и включите «Закрывать в трей».

## Zapret не запускается

### «Нужны права администратора»

`winws.exe` использует драйвер WinDivert, которому нужны права администратора.
Откройте **Настройки → Движки** и нажмите **«Перезапустить от администратора»**.
Приложение перезапустится с UAC-запросом и сохранит настройки.

### «winws.exe не найден» / «Движок не установлен»

```powershell
python scripts/fetch_engines.py --zapret --force
Test-Path engines\zapret\bin\winws.exe
```

Для установленной версии движок лежит в
`%LOCALAPPDATA%\Programs\Zentrix\engines\zapret`. Если папка пуста, откройте
**Обновления → Zapret → Установить** (нужен интернет) или переустановите
приложение.

### «cannot access ipset file …ipset-exclude-user.txt»

Zentrix создаёт пользовательские списки `lists\ipset-exclude-user.txt`,
`lists\list-general-user.txt` и `lists\list-exclude-user.txt` автоматически
перед первым запуском — так же, как это делает `service.bat` в оригинальном
Zapret. Если ошибка осталась, проверьте, что папка движка доступна для записи
(не находится в защищённой системной папке) и что антивирус не удаляет файлы
из `lists\`.

### Процесс запускается и сразу завершается

1. Выберите другую стратегию: не все `.bat` подходят вашему провайдеру.
2. Нажмите **«Проверить стратегию»** на странице Zapret — Zentrix временно
   запустит её и опросит YouTube, Discord, Telegram и GitHub. Если не работает
   ни одна знакомая стратегия, нажмите **«Поиск лучшей стратегии»**: Zentrix
   поочерёдно проверит все `.bat`, покажет рейтинг и выберет лучшую.
3. Проверьте лог на странице Zapret: там видны аргументы и stderr.
4. Убедитесь, что другой экземпляр `winws.exe` не запущен:
   ```powershell
   Get-Process winws -ErrorAction SilentlyContinue | Stop-Process -Force
   ```
5. Конфликт с другим DPI-обходчиком (GoodbyeDPI, Zapret из другого лаунчера)
   или VPN. Остановите их.
6. Антивирус может удалять `WinDivert64.sys`. Добавьте папку движка в
   исключения и переустановите Zapret.
7. Некоторые провайдеры блокируют сам WinDivert — попробуйте другую стратегию
   или Happ/Hiddify.

### Игры не подключаются

Проверьте игровой фильтр в настройках Zapret. Когда фильтр выключен, Zentrix
подставляет порт `12`, чтобы не перехватывать игровой трафик. Включите фильтр
и добавьте нужные порты/процессы в настройках движка.

### После обновления пропали мои списки

Обновление сохраняет `lists/` и `utils/game_filter.enabled`. Если списки всё же
потерялись, они могли быть в старой папке `engines\zapret.old-*` — проверьте её
и скопируйте `lists/` вручную.

## Happ / Hiddify

### «Ядро не установлено»

Откройте страницу движка и нажмите **«Скачать ядро»**. Или вручную:

```powershell
python scripts/fetch_engines.py --cores
```

Ядра: `engines\xray\core\xray.exe` для Happ и
`engines\singbox\core\sing-box.exe` для Hiddify.

### Ошибка 403 / rate limit при скачивании

GitHub ограничивает анонимные запросы. Подождите час или задайте токен:

```powershell
$env:GITHUB_TOKEN = "ghp_..."
```

Токен нужен только для API-запросов; скачивание релизов работает и без него.
Не публикуйте токен и не сохраняйте его в репозитории.

### «Не удалось разобрать ссылку»

Поддерживаются `vless://`, `vmess://`, `trojan://`, `ss://`. Ссылка должна быть
полной, без пробелов и обрезанных параметров. Для подписок используйте URL
подписки, а не отдельную ссылку. Проверьте, что ссылка ещё активна.

### Порт занят

Happ по умолчанию использует SOCKS `10808` и HTTP `10809`, Hiddify — mixed
`2080` и API `9091`. Если порт занят, измените его в настройках страницы.
Проверить занятость:

```powershell
Get-NetTCPConnection -LocalPort 10808,10809,2080,9091 -ErrorAction SilentlyContinue
```

### Интернет пропал после закрытия

Zentrix сбрасывает системный прокси при штатном выходе. Если приложение было
завершено принудительно, отключите прокси вручную:

**Параметры → Сеть и Интернет → Прокси → Автоматическое определение** или
выполните:

```powershell
netsh winhttp reset proxy
```

Затем проверьте **Параметры → Сеть → Прокси** и снимите галочку с ручного
прокси.

### 2ip.io показывает прежний IP

Подключение к серверу само по себе не меняет маршрут Windows: ядро слушает
локальный порт, а программы идут через него только при включённом системном
прокси.

1. Включите **«Системный прокси»** на странице Happ/Hiddify или нажмите
   **«Включить системный прокси»** в предупреждении.
2. Переподключитесь и нажмите **«Проверить внешний IP»** — появится IP туннеля.
3. Откройте `https://2ip.io/` в браузере. IP должен совпасть с полученным.

Если IP не меняется:

- Проверьте, что в Windows включён ручной прокси:
  **Параметры → Сеть и Интернет → Прокси**.
- Firefox с собственным прокси или Chrome с расширением могут игнорировать
  системный прокси — отключите их собственные настройки.
- Убедитесь, что узел работает: нажмите «Проверить задержку» и «Проверить
  внешний IP».

### Узел не подключается / таймаут

- **XHTTP** поддерживается только в Happ (Xray). Hiddify (sing-box) не умеет
  XHTTP и покажет понятную ошибку — выберите узел WS/TCP или вкладку Happ.
- **Reality** в sing-box может не проходить проверку
  (`reality verification failed`). В этом случае используйте узел **Резерв**
  (WS/TLS) или Happ.
- Узлы WS/TLS (обычно порт `8443`) — самый совместимый вариант.

## Мониторинг и проверки

- **Графики пустые.** Монитор по умолчанию остановлен — включите его на
  странице мониторинга и подождите 2–3 секунды. Если адаптер отключён, данные
  не поступают.
- **Нет соединений.** Windows может скрывать владельцев TCP-соединений без прав
  администратора. Запустите Zentrix от администратора.
- **Проверки показывают «заблокировано», хотя сайт открывается.** Проверка
  использует системный DNS и TLS SNI; VPN/DoH в браузере могут давать другую
  картину. Смотрите детали по каждому этапу (DNS, TCP, TLS).
- **Проверка зависла.** Она ограничена таймаутами; дождитесь завершения или
  нажмите «Остановить». Проверки выполняются в фоновом потоке и не блокируют
  окно.

## Внешний вид и производительность

### Чёрный или пустой фон с видео

- Поддерживаются форматы, которые умеет Qt Multimedia (MP4/H.264, WebM и др.).
  Если кодек недоступен, Zentrix вернётся к градиенту.
- Убедитесь, что файл не повреждён и доступен по указанному пути.
- Отключите видео в **Настройки → Оформление**, чтобы вернуть статический фон.

### Интерфейс тормозит

- Уменьшите интервал мониторинга (не чаще 1 раза в секунду) и отключите
  соединения.
- Отключите анимации и видео-фон.
- Закройте неиспользуемые страницы: они остановят свои таймеры при уходе.
- Не запускайте portable-версию с сетевого диска.

### Размытый интерфейс / неправильный масштаб

Zentrix использует PassThrough DPI. Если текст размыт, проверьте масштаб
Windows (100/125/150%) и перезапустите приложение. Дробное масштабирование
может требовать перезапуска после смены монитора.

### Окно не перетаскивается

Тяните за title bar, а не за фон. Двойной клик по title bar разворачивает окно.
Изменить размер можно за края/углы — они обрабатываются нативно.

## Обновления

- **«Репозиторий не найден»** для самого Zentrix — локальная сборка без
  опубликованного репозитория. Это ожидаемо; укажите свой репозиторий в
  **Настройки → Обновления**.
- **404 для компонента.** Проверьте интернет и название репозитория. Обновление
  Happ/Hiddify скачивает официальный установщик в `engines/<key>/vendor`.
- **Обновление Zapret.** Не запускайте его во время работы Zapret — сначала
  остановите обход. После обновления проверьте стратегию.

## Очистка

- Предпросмотр показывает только безопасные категории: кэш Zentrix, временные
  файлы приложения, старые логи и загрузки. Системные папки не затрагиваются.
- Файлы, занятые другим процессом, пропускаются. Закройте приложение и
  повторите.
- Автоочистка при старте по умолчанию выключена. Включайте её осознанно.

## Установка и удаление

- Установщик ставит приложение в `%LOCALAPPDATA%\Programs\Zentrix` и не требует
  прав администратора.
- Удаление через **Параметры → Приложения** сохраняет
  `%APPDATA%\Zentrix` (настройки, пресеты, профили). Чтобы удалить всё:
  ```powershell
  Remove-Item "$env:APPDATA\Zentrix" -Recurse -Force
  ```
- Если установщик пишет, что Zentrix запущен, закройте окно и иконку в трее
  (или завершите процесс `Zentrix.exe`), затем повторите.

## Сброс настроек

Закройте Zentrix и переименуйте файл настроек — при следующем запуске будут
созданы значения по умолчанию:

```powershell
Rename-Item "$env:APPDATA\Zentrix\settings.json" "settings.backup.json"
```

Если приложение не стартует из-за повреждённого JSON, оно само переименует его
в `settings.broken.json`.

Полный сброс (включая пресеты и профили):

```powershell
Remove-Item "$env:APPDATA\Zentrix" -Recurse -Force
```

## Как сообщить об ошибке

Приложите:

1. версию Zentrix (title bar или **Настройки → О программе**);
2. версию Windows (`winver`);
3. шаги воспроизведения;
4. последние 100 строк лога;
5. скриншот (без ссылок на подписки и токенов).

Не прикладывайте `settings.json`, если в нём есть приватные ссылки. Создайте
issue: <https://github.com/w1kscc/Zentrix/issues>.
