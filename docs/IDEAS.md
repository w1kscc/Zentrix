# Zentrix — банк идей фич

Все предложения из обсуждения, собранные в один список. Группы: VPN/прокси, Zapret,
проверки/мониторинг, автоматизация, UX/система, сеть/сеть Windows, безопасность,
сообщество, «не тащить».

Обозначения: ⭐ — рекомендовано (сильная польза при малых трудозатратах и опоре
на существующий код), 💎 — большой, но важный feature, ❗ — остерегаться раздувания.

## 1. VPN / прокси

- ⭐ Подписки (subscription URL): вставка ссылки, автообновление списка серверов по таймеру
- ⭐ Реальный замер задержки серверов (HTTP-тест через outbound каждого сервера,
  показ ping рядом с сервером + «выбрать лучший»)
- 💎 Split tunneling: гнать через VPN только выбранные приложения/домены
  (sing-box `route.rules` + process_name, Xray routing)
- 💎 TUN-режим / системный VPN через sing-box tun + wintun
- Fallback / цепочки: авто-переход на второй сервер при падении первого
  (sing-box `urltest`/`fallback` outbound-группы)
- ⭐ Экспорт/импорт профилей серверов (JSON бэкап) + QR-код своего ключа для телефона
- Кастомный DNS / DoH / DoT в конфиге ядра + проверка «утечки DNS» на странице проверок

## 2. Zapret

- ⭐ Watchdog `winws.exe`: следить за живостью, автоперезапуск + тост при падении
- Редактор собственных стратегий: визуальный список аргументов `winws.exe`,
  свои профили и списки доменов
- 💎 Автозапуск Zapret при старте Windows (через задачу планировщика — нужны админ-права)
- Следить за новыми стратегиями в релизах Flowseal и предлагать обновление

## 3. Проверки и мониторинг

- ⭐ История проверок блокчеков в SQLite (`cache.db`) + график «сервис доступен N% времени»
- ⭐ Планировщик проверок: тихая проверка раз в N часов + тост/звук при новых блокировках
- ⭐ Встроенный speedtest через активное ядро/стратегию (сравнение стратегий по скорости)
- ⭐ Статистика трафика по дням/месяцам и по приложениям (psutil уже в `netmon.py`)
- История замеров скорости с графиком динамики
- Экспорт всего (статистика, история проверок, события) в CSV/JSON
- Карта серверов / точка exit-ноды на мини-глобусе (флаги из `flags.py` уже есть)
- Инфо об IPv6: поддержка, доступность, утечки
- ⭐ Алерт при смене внешнего exit IP («был …, стал …»)

## 4. Автоматизация и сценарии

- ⭐ Правила-сценарии «если → то» («YouTube недоступен → стратегия №5»,
  «VPN пропал → включить Zapret») на базе `blocking_check` и движков
- Профили по Wi-Fi: «дома — напрямую, на чужом SSID — авто включение VPN»
- 💎 Kill Switch: при обрыве VPN блокировать весь интернет (правила WFP/файрвола)
- Расписание по времени («VPN по будням с 9:00 до 18:00»)
- 💎 Игровой профиль одной кнопкой (Game Mode): Zapret + игровой порт-фильтр
  (`game_scan.py`) + приоритет процесса (`SetPriorityClass` / power plan)

## 5. UX / система

- ⭐ Глобальные хоткеи: Ctrl+Alt+Z — Zapret, Ctrl+Alt+V — VPN (`registerHotkey`, `winapi.py`)
- ⭐ Палитра команд Ctrl+K — поиск по всеми действиям приложения
- ⭐ Авто-светлая/тёмная тема по системной (реестр `AppsUseLightTheme`)
- ⭐ Визард первого запуска: язык → проверка блокировок → готовая стратегия по результатам
- История событий: единая лента «15:02 VPN включён, 15:05 winws перезапущен…»
- Jump List в панели задач (ПКМ по иконке: Zapret вкл/выкл, VPN вкл/выкл, сервер)
- Меню трея с быстрым выбором VPN-сервера
- Экспорт/импорт тем и пресетов оформления (шаринг между пользователями)
- Онбординг-тур по страницам с подсветкой элементов (Q-overlay уже есть)
- CLI: `Zentrix.exe --vpn on --zapret off --profile 2` для скриптов и автозапуска
- Кнопка «Сообщить о проблеме»: диагностический zip (версия, обрезанные логи, ОС)

## 6. Сетевые инструменты Windows (натуральное расширение бренда «сеть — одно окно»)

- ⭐ Кнопка «починить сеть»: `flushdns` + сброс winsock + перезапуск адаптера одной кнопкой
- ⭐ Быстрая смена DNS (Cloudflare/Google/AdGuard/свой) через `netsh` на активном адаптере
  + тест скорости DNS
- ⭐ Ping / traceroute / whois / порт-скан — на страницу «Проверки»
- Менеджер hosts-файла: группы правил (реклама/трекеры) включаются одним тумблером
- Контроль автозапуска Windows: реестр Run, Startup, планировщик — с отключением
- Аудит Wi-Fi-паролей (`netsh wlan show profile`) + экспорт сети в QR-код
- Wake-on-LAN: magic packet по MAC
- Сканер локальной сети: устройства Wi-Fi-сети (IP/имя/MAC/производитель)
- Список открытых портов «что слушает на машине» + процесс
  (TCP-таблица уже в `netmon.py`)
- Список клиентов LAN-шеринга: кто подключился к вашему HTTP/SOCKS прокси
- Генератор PAC-файла для настройки браузеров на локальный прокси без системного прокси
- Встроенный мини-браузер (`QWebEngineView`) через SOCKS-прокси: проверить YouTube
  внутри Zentrix
- 💎 Проверка NAT-типа и UPnP-проброса портов (боль игроков с Discord/Steam)
- 💎 Traffic shaping: ограничение скорости выбранных процессов («не дать Steam
  сожрать канал во время игры»)

## 7. Безопасность и приватность

- ⭐ Шифрование ключей серверов через Windows DPAPI (сейчас URI в чистом виде в `%APPDATA%`)
- ⭐ Проверка SHA-256 при обновлении ядер Xray/sing-box/zapret
- Монитор камеры/микрофона: индикатор в трее, какой процесс использует устройство

## 8. Развитие проекта

- 💎 Мультиязычность (i18n, английская локализация) — резко расширяет аудиторию

## 9. Идеи, которые НЕ рекомендую тянуть в проект ❗

- Буфер обмена, скриншотер, хеш-суммы, шредер файлов — это уже другая программа;
  размывают фокус и угрожают холодному старту (~1,5 сек) и простоте интерфейса.
